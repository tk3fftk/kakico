## リリース版との比較の制約

Homebrew版に対応する `v0.1.2` との比較も最終実行の `comparison.md` に保存した。
現在ブランチは影を描くため、描画内容は v0.1.2 と異なる。
キャッシュ描画の中央値は28条件中18条件で v0.1.2 の通常描画より短い。
図形1個、および4K・20個の10条件はまだ v0.1.2 より遅い。
また初回のキャッシュ生成には影付き全要素の描画が必要であり、定常フレームと同じ速度にはならない。
本変更は作業開始時の現在ブランチのキャッシュ描画を改善するもので、全操作がリリース版より速いという結果ではない。
